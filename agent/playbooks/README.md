# Playbooks

Готовы две переносимые стратегии:

- `audit.md` — поиск доказуемого source-to-sink пути, формирование требуемого
  артефакта и обязательная проверка, что проект не изменён;
- `fix.md` — воспроизведение дефекта, минимальное исправление, повторный аудит,
  compile/test и контроль diff.

Стратегия `forensics.md` — следующий этап C-07; `ctf.md` будет добавлен после
проверки базовых классов задач.
