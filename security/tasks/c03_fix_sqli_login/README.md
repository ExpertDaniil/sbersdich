# Решение C-03: fix-sqli-login

Самостоятельный пакет для проверки минимального исправления SQL-инъекции в `POST /login`.

Состав:

- `routers/auth.py` — готовая безопасная версия файла;
- `fix_sqli_login.patch` — patch для публичной учебной копии;
- `tests/test_auth_fix.py` — автономные проверки на стандартной библиотеке Python;
- `verify.sh` — единая команда проверки;
- `C03_REPORT.md` — разбор причины, исправления и критериев готовности.

Запуск автономной проверки:

```bash
chmod +x verify.sh
./verify.sh
```

Пакет не изменяет публичный GitHub-репозиторий и не содержит эталонных ответов скрытого бенчмарка.
