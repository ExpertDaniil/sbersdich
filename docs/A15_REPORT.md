# A-15 — перенос на официальные варианты

Проведён местный прогон на шести официальных задачах из
`competition/main`. Рабочие папки создавались во временном каталоге, поэтому
исходный официальный набор остался неизменным.

| Задача | Режим | Результат | Изменение |
|---|---|---|---|
| `hello-file` | общий | пройдена | создан `hello.txt` |
| `bye-file` | общий | пройдена | создан `bye.txt` |
| `find-sqli-login` | аудит | пройдена | создан `security_report.json` |
| `fix-sqli-login` | исправление | пройдена | изменён `routers/auth.py` |
| `fix-sqli-search` | исправление | пройдена | изменён `routers/items.py` |
| `incident-log-forensics` | форензика | пройдена | создан `incident_report.txt` |

Дополнительно прошли отдельные проверки C-06, C-07 и C-08: поиск и исправление
обеих SQL-инъекций, построение четырёх полей отчёта по девяти артефактам,
проверка неизменности доказательств и режимные правила изменений.

Во всех проверках зафиксировано:

- официальный репозиторий не изменён;
- эталоны и готовые решения не читались;
- результаты получены из инструкции и доступной рабочей среды;
- подробные протоколы сохранены в `evaluation/results/c06_public/`,
  `c07_public/`, `c08_public/` и `c09_public/`.

Пункт остаётся частично выполненным до прогона полного входа `run.sh` в Linux и
испытания на дополнительных вариантах с изменёнными путями и шумом.
