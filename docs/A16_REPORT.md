## Проверки

- В наборе агента успешно выполнены 203 проверки. Ещё 11 корректно пропущены
  из-за отсутствия POSIX, pytest и прав на символические ссылки в текущей
  Windows-среде.
- В оценочном контуре успешно выполнены 79 проверок. Ещё 3 проверки
  символических ссылок корректно пропущены из-за ограничений Windows.
- Проверка распакованного архива подтвердила корневой `run.sh`, окончания строк
  LF, исполняемый режим, отсутствие тестов, файлов разработки и файлов с
  признаками секретов.
- Python-точка запуска из распакованного архива решила три независимых
  CTF-варианта.
- Корневой `run.sh` из распакованного архива запущен через Git Bash. Он решил
  публичные простые задания `hello-file` и `bye-file`, создал точные файлы из
  5 и 3 байт и не обращался к модели.
- Исправлена переносимость проверки опасного ZIP-пути `agent\escape.py`:
  стандартная библиотека Windows нормализовала его до проверки и создавала
  ложный провал теста. Сам запрет обратной косой черты в проверяющем коде уже
  присутствовал и не ослаблен.

## Что остаётся перед окончательной фиксацией

На текущем компьютере Docker отсутствует, поэтому здесь нельзя повторить запуск
в Linux-образе `secureintelligent/acp`. Сам `run.sh` проверен через Git Bash, а
в ветке C15 уже зафиксирован результат C16 6/6 для предыдущего кандидата. После
объединения командных веток нужно один раз пересобрать архив и повторить
контейнерный прогон.

A-16 считается готовой местно как воспроизводимый кандидат. Окончательная
фиксация версии зависит от согласованного слияния командных веток.
