# A-04 — простые задачи

Проверены две официальные задачи из ветки `competition/main`:

| Задача | Требуемый файл | Результат | Шаги | Запросы к модели |
|---|---|---|---:|---:|
| `hello-file` | `hello.txt` с текстом `Hello` | пройдена | 2 | 0 |
| `bye-file` | `bye.txt` с текстом `Bye` | пройдена | 2 | 0 |

В каждом случае первый шаг записал точное содержимое, а второй вызвал общий
проверяющий модуль. Он подтвердил существование файла, точное содержимое и
допустимость изменения. Результаты местного прогона находятся в игнорируемом
Git каталоге `evaluation/results/a04_local/`.

Проверка подтверждает, что известные простые задачи не требуют модели, ключа и
токенов. Подключение к модели создаётся отложенно, только если локальный
алгоритм не может выбрать следующее действие.
