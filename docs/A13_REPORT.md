# A-13: измерение эффективности контекста

## Цель

Проверить на одинаковых входах, что короткая история уменьшает запрос к
локальной модели и не теряет последнее важное наблюдение, от которого зависит
следующее действие.

## Что реализовано

- Рабочий `LocalModelActionDriver` уже передаёт последние 6 событий и не более
  2000 символов на краткое описание и данные одного результата.
- Оценочный драйвер меняет только число событий внутри проверки и повторно
  использует рабочее преобразование каждого события. Основной файл выбора
  действий не меняется, чтобы не пересекаться с экспериментальной веткой
  конвейера гипотез.
- `evaluation.context_efficiency` сравнивает 24 события с рабочим окном из 6
  событий на четырёх режимах: аудит, исправление, расследование и общий.
- Подменный транспорт возвращает успешное действие только если в запросе
  осталось последнее важное наблюдение. Поэтому простое уменьшение запроса с
  потерей существенных данных не может дать положительный результат.
- При прогоне с настоящей моделью учитываются фактические входные токены из её
  поля `usage`, а необязательные параметры действий приводятся к значениям по
  умолчанию перед сравнением.
- Неуспешный сетевой прогон можно продолжить по прежнему отчёту: успешные
  сценарии сохраняются, остальные повторяются с настраиваемой паузой между
  запросами. Текущий сценарий выводится до обращения к модели.

## Результат местного прогона

Команда:

```bash
python3 -m evaluation.context_efficiency \
  --output evaluation/results/a13_context_efficiency.json
```

| Показатель | Полная история | Короткая история | Изменение |
|---|---:|---:|---:|
| Событий на сценарий | 24 | 6 | −75% |
| Размер четырёх запросов | 313149 байт | 94881 байт | −69,70% |
| Грубая оценка входных токенов | 78288 | 23721 | −54567 |
| Совпавшие действия | 4/4 | 4/4 | без ухудшения в детерминированной проверке |
| Последнее важное наблюдение сохранено | 4/4 | 4/4 | без потерь |

Порог проверки — не менее 45% экономии. Фактическое сокращение составило
69,70%, все четыре сценария прошли.

## Проверка через Gemini

Дополнительный прогон выполнен через совместимый адрес Gemini 3.5 Flash. Два
полностью завершённых сценария дали 28 712 входных токенов для полной истории
и 8 858 для короткой: экономия составила 19 854 токена, или 69,15%. В обоих
случаях выбранные действия совпали и последнее важное наблюдение сохранилось.

Оставшиеся два сценария не завершились из-за ответа 429. Сам адрес сообщил об
исчерпании бесплатной квоты в 20 запросов; это ограничение внешней проверки, а
не расхождение действий или потеря контекста. По решению команды A-13 считается
пройденной на основании воспроизводимого результата 4/4 и подтверждённого
фактического сокращения токенов на завершённых запросах.

Оценка токенов рассчитана отдельно по правилу «четыре байта на токен» и не
смешивается с фактическим полем `usage`, которое вернёт конкретная модель.

## Граница вывода

Этот результат доказывает размер запроса и сохранение требуемой информации в
воспроизводимой местной проверке. Он не подменяет прогон качества на конкретной
модели. Когда будет доступен итоговый локальный адрес, та же проверка запускается
с `--live`; она делает два запроса на сценарий, но не выполняет выбранные
инструменты и не изменяет проект. При временной ошибке продолжение запускается
с `--live --resume --cooldown-seconds 20` и тем же путём `--output`.
