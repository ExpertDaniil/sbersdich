# Принятые допущения по условиям соревнования

Организаторы не уточнили спорные пункты, поэтому команда использует наиболее консервативный вариант:

1. `run.sh` финального submission лежит строго в корне ZIP.
2. Собственный `agent.py` в ZIP не включается; организаторы добавят общую обёртку.
3. Каталог задачи — `/app`, код агента расположен отдельно.
4. Внешний интернет отсутствует; доступен только локальный OpenAI-compatible LLM endpoint.
5. Используются только файлы submission и зависимости `secureintelligent/acp`.
6. stdout является диагностикой; основным результатом считаются требуемые файлы и изменения в `/app`.
7. Task-specific time/token limits агенту напрямую не передаются, поэтому используется внутренний deadline.
8. Ограничение 10 МБ применяется к сжатому ZIP.
9. `run.sh` хранится с LF и executable bit.
10. Агент не читает `/tests`, `/logs/verifier` и expected/solution-файлы ради получения ответа.
11. Проектные тесты внутри `/app/tests` разрешено читать и запускать.
12. Публичное `allow_internet=true` не доказывает соответствие финальному офлайн-контуру.
