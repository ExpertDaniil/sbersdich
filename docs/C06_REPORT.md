# C-06 — универсальные audit/fix-компоненты

## Результат

В `agent/` добавлен первый исполняемый слой будущего ИБ-агента:

- `strategies.py` выбирает режим `audit`, `fix`, `forensics` или `general`;
- `tools/security_scan.py` строит простой taint-flow от аргументов функции к
  SQL-вызовам и выдаёт машиночитаемый audit-отчёт;
- `tools/sql_parameterize.py` переводит поддерживаемые f-string SQL-значения на
  параметры `$1`, `$2`, ... и передаёт данные отдельными аргументами;
- `playbooks/audit.md` запрещает незапрошенное изменение проекта;
- `playbooks/fix.md` требует минимальный diff и полный цикл перепроверки.

Все компоненты используют только стандартную библиотеку Python.

## Границы автоматического исправления

Исправитель намеренно работает узко: asyncpg-подобные вызовы
`execute`/`fetch`/`fetchrow` и f-string-интерполяция значений. Он умеет
переносить `%` для `LIKE` в значение параметра. Интерполяция идентификаторов,
`.format`, `%`-форматирование и неоднозначно собранные запросы остаются основному
агенту — автоматическая эвристика не должна портить проект.

Аудитор охватывает больше конструкций, чем fixer, и поэтому может безопасно
сообщить о проблеме, которую нельзя переписать автоматически.

## Проверки

`./agent/verify.sh` запускает 12 тестов:

- обнаружение присвоенного SQL f-string;
- отсутствие false positive на безопасном построении `$N` placeholders;
- обнаружение `.format`, `%` и интерполяции SQL-идентификатора;
- отсутствие дублей для вложенных функций;
- точная схема audit JSON;
- исправление login и LIKE search;
- поведенческая проверка, что payload остаётся отдельным параметром;
- отказ от рискованной автозамены идентификатора;
- неизменность файлов в `--check` и audit-режимах;
- классификация audit/fix/forensics-инструкций.

`./scripts/run_c06_public.sh PATH` дополнительно копирует публичные SQL-задачи во
временный каталог и проверяет:

- audit находит уязвимость, но не изменяет исходники;
- обе fix-задачи имеют finding до исправления и ноль после;
- исправленный Python-код компилируется;
- хеши исходного публичного репозитория не меняются.

Полный `pytest` приложений, зависящий от FastAPI/PostgreSQL, остаётся частью
Docker-контура C-04. C-06 проверяет переносимую логику, синтаксис и поведение
параметризации без добавления зависимостей.

## Воспроизводимые команды

```bash
./scripts/check_all.sh
./scripts/run_c06_public.sh /absolute/path/to/UniversalAgenticCompetitionPublic
```
