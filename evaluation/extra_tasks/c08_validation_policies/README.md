# C-08 validation policies

Unit-тесты создают временные проекты и проверяют положительные и отрицательные
варианты audit/fix/forensics/general: лишние изменения, правку tests и manifests,
сломанный синтаксис, неверные артефакты, timeout и точное содержимое файла.

Эти сценарии остаются в evaluation/tests и не включаются в финальный runtime.
