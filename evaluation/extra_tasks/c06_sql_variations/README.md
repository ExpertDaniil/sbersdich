# C-06 SQL variations

Каталог зарезервирован для независимых вариаций SQLi-задач: другие имена
аргументов, прямые и присвоенные запросы, LIKE-шаблоны, безопасные динамические
плейсхолдеры и неподдерживаемая интерполяция идентификаторов.

Проверки C-06 генерируют эти варианты во временных каталогах, поэтому expected
и готовые исправления не попадают в доступную агенту часть репозитория.
